# Curio

Curio is a mobile learning app that helps children explore the world around them through camera-based object scanning. The app allows users to scan everyday objects and receive simple, fun, age-appropriate educational facts.

## Project Overview

Curio is designed to make learning more interactive and engaging for children. Instead of only reading from books or screens, children can use their mobile device camera to discover information about real-world objects around them.

For example, a child can point the camera at a tree, fruit, toy, or household object, and the app will display a short learning explanation or fun fact.

## Core Feature

The main feature of Curio is object scanning using the mobile camera.

The app will:

- Access the mobile camera
- Scan or identify real-world objects
- Display educational facts about the detected object
- Provide a simple and child-friendly interface

## Features

- Camera-based object scanning
- Educational fun facts
- Child-friendly user interface
- Object result screen
- Discovery history
- Parent/guardian section
